Greed vs Fear — Trader Sentiment Analysis
A data science project that analyses HyperLiquid trader behaviour across different market sentiment conditions 
(Fear, Greed, Neutral etc.) using historical trade data and a Fear & Greed index.

SET UP:
Project Files
fear_greed_index.csv      ← Fear & Greed sentiment data (input)
historical_data.csv       ← Raw trade history data (input)
TradeAnalysis.ipynb       ← Jupyter Notebook (data cleaning, analysis, charts)
StreamlitDashboard.py     ← Interactive web dashboard
Closed_Trades.csv        ← Auto-generated by the notebook (used by dashboard)

Important: Run the Jupyter Notebook first. It creates Closed_Trades.csv which the dashboard needs.
Requirements
Clone the requirements.txt file in your desktop
Run this command on terminal: pip install -r requirements.txt

How to Run
Step 1 — Run the Jupyter Notebook
Then inside the notebook, click Run All (from the top menu: Cell → Run All).

This will:

Load fear_greed_index.csv and historical_data.csv
Clean and merge the data
Calculate key metrics (win rate, drawdown, PnL, aggression etc.)
Generate and save all 19 charts as .png files
Save the final processed data as Closed_Trades.csv


Step 2 — Run the Streamlit Dashboard
Once Closed_Trades.csv exists, open a terminal in your project folder and run:
bashstreamlit run StreamlitDashboard.py
Your browser will automatically open at localhost

The dashboard includes: 4 interactive charts, Predictive model, Trader clustering 

4 interactive charts — Coin × Sentiment heatmap, Hourly win rate, Monthly PnL, Coin Long vs Short breakdown
Predictive model — Predicts whether tomorrow will be a Loss, Small Gain or Big Gain based on today's behaviour and sentiment
Trader clustering — Groups all 32 accounts into behavioural archetypes using K-Means
